# Achados UFLA

Sistema web para cadastro e recuperação de objetos perdidos e encontrados no
ambiente universitário.

> Projeto acadêmico da disciplina GAC116 — Programação Web.

## Status

Em desenvolvimento — Checkpoint 1.

## Tecnologias

- Django;
- banco de dados relacional;
- React;
- Bootstrap ou equivalente;
- Git e GitHub.

## Estrutura

```text
achados-ufla/
├── backend/   # aplicação Django
├── frontend/  # aplicação React
├── docs/      # documentação pública do projeto
├── .gitignore
└── README.md
```

## Requisitos

- Python 3.13 ou versão definida pelo grupo;
- Node.js LTS;
- npm.
